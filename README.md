# DukaanAI

Hackathon prototype: a Hindi-friendly merchant dashboard connected to an explainable restocking API.

Run with Python 3.10+: `python backend/server.py`, then open http://localhost:8000. Demo figures are fictional.

- `frontend/`: responsive UI and API client
- `backend/server.py`: static server plus JSON endpoints
- `backend/forecast.py`: transparent weighted-demand estimate and order suggestion
